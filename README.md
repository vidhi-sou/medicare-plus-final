
# MediCare+ — Doctor Appointment Management System

🌐 **Live Website:** https://medicare-plus-yc5d.onrender.com/

💻 **GitHub Repository:** https://github.com/vidhi-sou/medicare-plus

## About the Project

MediCare+ is a web-based doctor appointment management system built with Flask. It helps patients and doctors manage appointment-related activities through a simple web interface.

## Features

- Patient registration and login
- Doctor appointment booking
- Appointment slot availability
- Patient and doctor dashboards
- Appointment history and status
- Ratings and reviews
- Admin dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML and CSS
- Git and GitHub
- Render for deployment
